📌 Project Overview

This repository contains the Header and Events sections of the official AWS Student Chapter website for Manipal Institute of Technology, Manipal.

The goal of this module is to deliver a premium, dark-themed, production-ready UI that aligns with professional cloud-tech branding standards.

This implementation focuses on:

Modern design principles

Clean layout structure

Smooth animations

Responsive behavior

AWS-inspired corporate aesthetics

🛠 Tech Stack

Next.js 14

React

Tailwind CSS

Framer Motion

Fully responsive design

Dark theme with AWS accent styling
